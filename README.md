# 💜 Ascii-studio 💜

*A normal text editor with everything you need to make ASCII art!*

[![Status: Live Preview](https://img.shields.io/badge/Status-Live%20Preview-7b2cbf?style=for-the-badge&logo=github&logoColor=white)](https://bedrock199.github.io/Ascii-studio/)

### ✨ Features
* **Classic Editing:** Simple and intuitive text-based layout.
* **ASCII Creation:** Designed specifically to help you craft clean, creative character art.
* **Browser Ready:** Runs instantly inside any modern web browser with zero installation required.

---

### 🚀 How to Open & Run

#### Option 1: Play Instantly (Live Web)
If you turn on **GitHub Pages** in your repository settings (under *Settings > Pages* and setting the branch to `main`), you can open and run your program directly from this URL:
👉 `https://bedrock199.github.io/Ascii-studio/`

#### Option 2: Run Locally
1. Click the green **[< > Code](https://github.com/BEDROCK199/Ascii-studio)** button at the top of the repository and choose **Download ZIP**.
2. Extract the files to your computer.
3. Double-click **[index.html](https://github.com/BEDROCK199/Ascii-studio/blob/main/index.html)** to open it in your favorite browser!
